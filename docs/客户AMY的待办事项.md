# 客户 Amy 的待办事项

## 1. 确认邮件转发地址（Gmail 转发验证）

背景：网站的 lead 邮件先发到我们的存档邮箱，再自动转发给 Amy。Gmail 添加转发地址时需要收件人验证。

**Amy 需要做的事**：

- Gmail 会往 Amy 的邮箱发一封验证邮件（发件人为 Gmail 团队，主题含「转发确认」/ "Forwarding Confirmation"）。
- Amy 需要打开那封邮件，**点击里面的验证链接**（或把邮件里的验证码告诉我们）。
- 验证完成后，转发设置即可生效，后续所有官网 lead 邮件会自动转发到 Amy 的邮箱。

## 2. 提供微信二维码图片

背景：网站的「微信」弹窗目前用的是占位图，需要换成 Amy 本人的微信二维码。

**Amy 需要做的事**：

- 打开微信 → 我 → 点自己头像 → 二维码名片 → 保存图片。
- 把二维码图片发给我们（建议清晰原图，≥400×400 像素）。
- 弹窗上已印有「添加时请备注：官网」，之后凡是带此备注的好友申请即为网站客户，**通过好友时请截图存档**（用作月底对账凭据）。
