# 客户演示脚本（15 分钟版）

## 演示前准备（10 分钟）

1. **启动本地网站**：终端里运行
   ```bash
   cd /Users/tingtinggu/CascadeProjects/AmyGEO/site && python3 -m http.server 8765
   ```
   浏览器打开 http://localhost:8765
2. **（强烈推荐，5 分钟）让表单真实收邮件**：去 https://web3forms.com 用你的邮箱免费拿一个 Access Key，填到 `assets/js/lead.js` 的 `web3formsKey: ""` 里。这样演示时当着客户面提交表单，**几秒后邮件就到**，是全场最有说服力的一幕。来不及就跳过，表单会降级为打开邮件客户端，照样能讲。
3. Chrome 按 F12 → 点击设备图标（Ctrl/Cmd+Shift+M）切到手机视图，先切好放着。

## 演示流程（按顺序讲）

### 第 1 步 · 开场：一句话定位（1 分钟）
桌面模式打开首页。说：**「这个网站的每一个联系入口都做了追踪，每一条咨询都能证明是网站带来的——这就是按 lead 结算的依据。」**

### 第 2 步 · 手机浮动栏（1 分钟）
切到手机视图刷新。指出底部常驻四按钮：**致电｜微信｜WhatsApp｜留言预约**。
卖点：华人客户 90% 用手机看，任何页面滑到哪里，联系方式都在拇指位置。

### 第 3 步 · 微信入口（2 分钟）
点「微信」按钮 → 弹出二维码 + 「复制微信号」+ **红字提示「添加时请备注：官网」**。
讲解：微信没法技术追踪，所以用"备注暗号"归因——Amy 看到备注"官网"的好友申请，就知道是网站来的，截图即凭据。（二维码目前是占位图，拿到 Amy 的码换一张图片就行。）

### 第 4 步 · WhatsApp 入口（1 分钟）
点「WhatsApp」→ 跳转 wa.me，消息框里**自动预填**「您好Amy，我在官网 amytorontofuneral.ca 看到您的服务…」。
讲解：客户不用打字直接发送，Amy 收到这句话就知道来源，同样截图即凭据。

### 第 5 步 · 专属转接电话（2 分钟）
现在页面显示的还是真实号。按 F12 打开 Console，粘贴这段模拟"配置好转接号之后"的效果：
```js
document.querySelectorAll('a[href^="tel:"]').forEach(a => {
  a.href = "tel:6475550000";
  a.textContent = a.textContent.replace(/647[-.\s]?649[-.\s]?9188/g, "647-555-0000");
});
```
全站电话瞬间变成 647-555-0000，但顶栏的微信号纹丝不动。
讲解：上线后买一个 Twilio 本地号（约 $2/月），网站只显示这个号，自动转接到 Amy 手机。**打进这个号的电话 100% 来自网站**，后台有每通电话的时间、号码、时长、录音，月底直接导出对账。刷新页面恢复原状。

### 第 6 步 · 预约表单（3 分钟）★ 重头戏
手机视图点「留言预约」滚到表单。当着客户面填一条测试：称呼"测试-张先生"、电话随意、类型选"预约参观墓园"，提交。
- 配好了 Web3Forms：打开邮箱给客户看刚收到的邮件——除了客户填的内容，**邮件里自动多了 6 个隐藏字段**：来源网站、着陆页、当前页、referrer、广告参数（UTM/gclid）、多伦多时间。
- 讲解：客户自己都不知道的情况下，每份表单自带"从哪来"的完整证据链。如果以后投小红书/谷歌广告，链接带上 utm 参数，连"哪条广告带来的"都能分清。
- 提交成功自动跳转感谢页（顺便展示）。

### 第 7 步 · AI 在线客服（3 分钟）
当前已开启**演示模式**（`lead.js` 里 `workerUrl: "demo"`），右下角自动显示「在线咨询」气泡，无需任何操作。
演示动线：点气泡 → 点快捷问题「买墓地大概多少钱？」→ AI 回答并请客户留联系方式 → 输入一个手机号发送 → AI 回复"已转达 Amy，24 小时内回复"。
（演示模式是本地模拟回复；正式上线部署 Worker 后，换成真实 AI，回答范围覆盖全部 32 条 FAQ。**上线前记得把 workerUrl 从 "demo" 改成 Worker 真实地址。**）
讲解要点：
- 上线后由 Gemini AI 驱动，**已经学习了网站全部 32 条 FAQ 和价目**，半夜两点也能用中文回答"骨灰能运回中国吗"这类问题；
- 最关键的一步：聊两三轮后 AI 会主动请访客留电话或微信，**访客一留下联系方式，Amy 立刻收到一封带完整聊天记录的邮件**——这就是一条可计费的 lead；
- 成本约几分钱一次对话，AI 只按网站内容回答，不会乱报价格。

### 第 8 步 · 收尾：对账方式（2 分钟）
总结三本账，互相印证、无法抵赖：
1. **GA4 统计**：8 个动作全记录（点电话、点微信、提交表单、AI 留资……），月底一张报表；
2. **Twilio 通话记录**：每通网站来电的原始记录+录音；
3. **邮件存档**：每条表单/AI lead 的邮件，自带来源字段和时间戳。
结算口径建议当场说清：接通 X 秒以上的电话、留了联系方式的表单/AI 对话、备注"官网"的微信好友，算一条有效 lead。

## 客户可能问的问题

- **“这些功能什么时候能上线？”** 网站代码已全部完成。需要开通四个免费/低价账号（Web3Forms、GA4、Twilio、Cloudflare），加起来 1-2 小时配置，可承诺一周内全部上线。
- **“成本多少？”** 固定成本只有 Twilio 号约 $2/月 + AI 客服 API 按用量（正常流量每月几加元）。其余全部免费额度内。
- **“电话录音合法吗？”** 安省允许单方同意录音，但建议转接时加一句提示音，或者不开录音、只记时间和时长。
- **“微信那个备注，客户不写怎么办？”** 确实有漏网，所以是五渠道互补；以后可升级企业微信"渠道活码"，扫码即自动统计，无需备注。
- **“会不会影响谷歌排名？”** 不会。转接号只出现在页面可见处，结构化数据和 Google 商家档案保留真实号，NAP 一致性是专门设计过的。
